# Responsive Breakpoints

Los Breakpoints corresponden a _medidas de anchura_ en las que se realizan cambios para el __diseño responsive__ y aplican los estilos CSS concretos. Es un valor de ancho, generalmente en pixeles, que se toma en cuenta _para fijar el límite entre dos dispositivos_. Ayudan a planificar y adaptar un diseño base a cada dispositivo, pues tiene una dimensión a tomar en cuenta sobre la que trabajar.

* __Son la base del diseño responsive__: Se utilizan para controlar cuándo se puede adaptar el diseño a una ventana gráfica o tamaño de dispositivo específico.
* __Media Queries para diseñar__: son una función de CSS que permite aplicar estilos condicionalmente según un conjunto de _parámetros del navegador_.
* __Diseño adaptable y móvil__: Busca aplicar la mínima cantidad de estilos para que un diseño funcione incluso en el punto de interrupción más pequeño, y luego aplicar capas de estilos para adaptarlo a dispositivos más grandes. Esto optimiza el CSS, mejora el tiempo de renderizado y ofrece una excelente experiencia a los visitantes

| breakpoint | screen-width | max-width | device-type |
|-|-|-|-|
| xs | - | 100% | smartwatch |
| sm | ≥576px | 540px | smartphone |

| xl | ≥1200px | 1140px | hd desktop |
| xxl | ≥1400px | 1320px | smart tv |
