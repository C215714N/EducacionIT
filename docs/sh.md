Comando IP

| comando | descripcion
|--|--|
| ip link show | Muestra las interfaces de red |
| ip route show | Muestra las rutas |
| ip neighbour show | Muestra la tabla arp |

Comando hostname

|Comando|
|--|
| hostname | Muestra nombre de Host | 
| hostnamectl | Muestra la configuracion del Host |
| hostnamectl set-hostname `<name>` | Permite cambiar el nombre del Host | 

Comandos Network Manager

|Comando|Descripcion|
|--|--|
| nmcli | Muestra la configuracion de Red |
| nmcli connection show |Muestra las conexiones de Red |
| nmcli device show| Muestra los dispositivos |
| nmcli radio wifi | Verifica el Estado de la conexion Wi-Fi |
| nmcli device wifi list | Muestra las conexiones inalambricas disponibles |
