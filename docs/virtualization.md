# Virtualizacion y Cloud Computing

La virtualizacion permite ejecutar multiples instancias de sistemas operativos o funciones de red sobre un unico hardware fisico, optimizando recursos.

## Componentes de Virtualizacion

1. __Hipervisor:__ Software que crea y ejecuta maquinas virtuales (VMs).
    * __Tipo 1 (Bare Metal):__ Se ejecuta directamente sobre el hardware (ESXi, Xen).
    * __Tipo 2 (Hosted):__ Se ejecuta sobre un sistema operativo anfitrion (VirtualBox, VMware Workstation).
2. __NFV (Network Functions Virtualization):__ Virtualizacion de servicios de red como firewalls, routers y balanceadores de carga.

## Cloud Computing

* __IaaS (Infrastructure as a Service):__ Proporciona hardware virtualizado.
* __PaaS (Platform as a Service):__ Proporciona plataformas para desarrollo.
* __SaaS (Software as a Service):__ Proporciona aplicaciones directas al usuario.

## Tipos de Nube

* __Privada:__ Uso exclusivo de una organizacion.
* __Publica:__ Disponible para el publico general (AWS, Azure, GCP).
* __Hibrida:__ Combinacion de nubes publicas y privadas.
* __Comunitaria:__ Compartida por organizaciones con intereses comunes.
