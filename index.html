Tipos de Diseño

Evolucion con el paso del tiempo

Fluid Design

Estilo predeterminado, donde el contenido se adapta al tamaño de los contenedores. No se establecen limites y uno de sus principales problemas es que los contenidos se estiran demasiado en pantallas grandes, resultando dificil la lectura de los mismos. Una solucion temporal a este problema fue la implementacion del Liquid Design, donde se establecian tamaños maximos y minimos para evitar el estiramiento y desbordamiento de contenidos.

Adaptive Design

Solucion para clientes con poco presupuesto, debido a que se crean diferentes versiones de un mismo sitio, adaptadas a los dispositivos objetivo. El problema con este diseño radica en la duplicidad de contenidos, lo que aumenta el costo de mantenimiento y la carga de trabajo del servidor. En muchas ocasiones se utilizaban hojas de estilos diferentes y segun la version, habia contenidos que no aparecian. Ademas de implementar herramientas de redireccionamiento, en base a la resolucion del dispositivo.

Responsive Design

Sugerido por primera vez en una publicacion del sitio A List Apart realizada por Ethan Marcotte, donde se plantean conceptos como multimedia flexible, sistemas de grillas, etc, implementando por primera vez el concepto One Web for All, que da nacimiento al diseño responsivo. El mismo consiste en la creacion de una unica estructura donde el contenido se adapta en base a las diferentes resoluciones en tiempo real, utilizando un sistema de grillas basado en porcentajes. Mismo sistema que adoptaria el equipo de Twitter para crear Bootstrap
