# Network Security

Esto es una guia para los alumnos de la capacitacion __Seguridad en Redes: Arquitectura y Defensa__ que cursan los dias _lunes y miercoles de 09:30 a 11:30hs_, donde podran acceder al material utilizado durante las clases y descargar el mismo.

## Herramientas 

* Sistemas Operativos
	* [Debian](https://debian.org)
	* [RedHat](https://redhat.com)
	* [Kali](https://kali.org)
	* [CentOS](https://centos.org)
* Analisis de Paquetes
	* [NMap](https://nmap.org)
	* [Wireshark](https://wireshark.org)
* [Cisco Packet Tracer](https://www.netacad.com/resources/lab-downloads?courseLang=en-US)
* [Emulador GNS3](https://www.gns3.com/)
	* [VM Server](https://www.gns3.com/software/download-vm)
	* [Cisco IOS](https://github.com/hegdepavankumar/Cisco-Images-for-GNS3-and-EVE-NG)
