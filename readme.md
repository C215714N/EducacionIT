# Seguridad en Redes

Esto es una guia para los alumnos de la capacitacion __network security server hacking__ que cursan los dias _martes y jueves de 19hs a 21hs_, donde podran acceder al material y descargar los contenidos trabajados durante las clases.

* [Network Mapper](https://nmap.org/)
