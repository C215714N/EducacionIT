Esto es una guia para los alumnos de la capacitacion __network security: server hacking__ que cursan los dias _sabados de 10hs a 13hs_, donde podran acceder y descargar el material trabajado durante las clases.

* [VirtualBox](https://virtualbox.org)

* [Wireshark](https://wireshark.org)
* [NMap](https://nmap.org)
