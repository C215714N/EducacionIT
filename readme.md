# Network Security

Esto es una guia para los alumnos de la capacitacion __Seguridad en redes: Arquitectura y Defensa__ que cursan los dias _martes y jueves de 10hs a 12hs_, donde podran acceder al contenido trabajado durante las clases y descargar el material utilizado durante las mismas.

## Herramientas

* Sistemas Operativos
    * [Debian](https://debian.org)
    * [RedHat](https://redhat.com)
    * [Kali](https://kali.org)
    * [CentOS](https://centos.org)
* Analisis de Paquetes
    * [NMap](https://nmap.org)
    * [Wireshark](https://wireshark.org)
* Simulacion de Topologias
    * [Cisco Packet Tracer](https://www.netacad.com/resources/lab-downloads?courseLang=en-US)
    * [Emulador GNS3](https://www.gns3.com/)
        * [VM Server](https://www.gns3.com/software/download-vm)
        * [Cisco IOS](https://github.com/hegdepavankumar/Cisco-Images-for-GNS3-and-EVE-NG)
