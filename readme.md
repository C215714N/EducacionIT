# CCNA 2

Esto es una guia para los alumnos de la capacitacion __ccna2 routing and switching__ que cursan los dias _sabados de 10hs a 13hs_ donde podran acceder al material utilizado durante las clases y descargar el contenido de los mismos.

## Herramientas

* [Packet Tracer](https://www.netacad.com/es/articles/news/download-cisco-packet-tracer)
* Emuladores de Terminal
    * [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html)
    * [TeraTerm](https://teratermproject.github.io/index-en.html)
    * [Driver Identifier](https://www.driveridentifier.com/blog/?p=149)
* Analisis de Paquetes
    * [Wireshark](https://www.wireshark.org/download.html)
    * [Nmap](http://nmap.org/download.html)
