# CCNA 3 (Cisco Certified Network Associated) 

Esto es una guia para los alumnos de la capacitacion __ccna 3 redes empresariales, seguridad y automatizacion__ que cursan los dias _martes y jueves de 19hs a 21:30hs_, donde podran acceder al contenido visto durante las clases y descargar el material utilizado durante las mismas.

## Herramientas

* [Packet Tracer](https://www.netacad.com/es/articles/news/download-cisco-packet-tracer)
* Emulador de Terminal
    * [PuTTY](https://putty.org/index.html)
    * [TeraTerm](https://teratermproject.github.io/index-en.html)
    * [SecurteCRT](https://www.vandyke.com/cgi-bin/releases.php?product=securecrt)
    * [MobaXTerm](https://mobaxterm.mobatek.net/download-home-edition.html)
    * [ZocTerminal](https://www.emtec.com/zoc/index.html)
