# Seguridad en Redes

Esto es una guia para los alumnos de la capacitacion __network security server hacking__ que cursan los dias _martes y jueves de 19hs a 21hs_, donde podran acceder al material y descargar los contenidos trabajados durante las clases.

## Herramientas

* Sistemas Operativos
	* [Debian](https://debian.org)
	* [CentOS](https://centos.org)
	* [RedHat](https://redhat.com)
	* [Kali](https://kali.org)
* [Oracle VirtualBox](https://www.virtualbox.org/)
* [Cisco Packet Tracer](https://www.netacad.com/portal/resources/packet-tracer)
* [Wireshark](https://wireshark.org)
