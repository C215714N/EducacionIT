# Seguridad en Redes

Esto una guia para los alumnos de la capacitacion __Network Security: Server Hacking__ que cursan los dias _miercoles y viernes de 09:15hs a 11:15hs_, donde podran acceder al contenido trabajado durante las clases y descargar el material utilizado durante las mismas.

## Herramientas

* Sistemas Operativos
    * [RedHat](https://redhat.com)
    * [CentOS](https://centos.org)
    * [Debian](https://debian.org)
    * [Kali Linux](https://kali.org)
* [Oracle VirtualBox](https://www.virtualbox.org/)
* [Cisco Packet Tracer](https://www.netacad.com/portal/resources/packet-tracer)
