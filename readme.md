Esto es una guia para los alumnos de la capacitacion __ccna 3 redes empresariales, seguridad y automatizacion__ que cursan los dias _martes y jueves de 19hs a 21:30hs_, donde podran acceder al contenido visto durante las clases y descargar el material utilizado durante las mismas.
